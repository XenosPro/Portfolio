# Anis — AI & Machine Learning Portfolio

Personal portfolio website showcasing selected work across machine learning, deep learning, LLM/API integration and full-stack AI applications.

**Live portfolio:** https://xenospro.github.io/Portfolio/

## Featured projects

- **Chiali Care Connect** — collaborative healthcare web application with authentication, appointments, a signed-in clinic assistant and FastAPI-powered diabetes risk screening.
- **Medical Insurance Cost Predictor** — end-to-end regression project using XGBoost with a deployed Streamlit interface.
- **Project Alpha** — Gemini-powered machine-learning quiz engine with structured outputs, validation, XP and streak tracking.
- **Tally** — full-stack budget and expense tracker with Supabase and AI-assisted receipt extraction.
- **Transfer Learning Study** — Cats vs. Dogs experiments across multiple ImageNet-pretrained CNN architectures.
- **Flappy Bird** — browser game built with HTML5 Canvas and vanilla JavaScript.

## Stack

Python · Pandas · NumPy · Scikit-learn · XGBoost · TensorFlow · Keras · FastAPI · Streamlit · React · TypeScript · Supabase · Git/GitHub

## Repository structure

- `index.html` — portfolio website served through GitHub Pages.
- `project_alpha/` — current source for the Project Alpha Streamlit app.
- `insurance_cost_prediction.ipynb` — legacy copy kept for now; the maintained insurance project lives in [XenosPro/insurance-calculator](https://github.com/XenosPro/insurance-calculator).

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server.
